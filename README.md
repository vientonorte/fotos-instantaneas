# fotos-instantaneas 📷✨

App de gestión operacional para Camila **@fotosinstantaneas.cl** — fotografía instantánea callejera en Santiago, Chile.

## Stack

React 19 · Vite 8 · TypeScript 5.7 · Tailwind CSS v4 · react-leaflet · html-to-image

## Funcionalidades

- 🖼 Flyer Polaroid descargable en 3 idiomas (ES/EN/PT)
- 🗺 Mapa interactivo OpenStreetMap con puntos de encuentro en Santiago
- 💰 Registro de ventas con ROI por sesión
- 🌈 Apoyo neurodivergente: check-in energía/mutismo, tarjetas de comunicación fullscreen, tareas ⭐
- 📋 Historial unificado filtrable y editable
- 📱 Responsive: sidebar en desktop, bottom tab bar en mobile
